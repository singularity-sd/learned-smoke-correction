# Development on validation, trajectories and built-in filter
The 144x144 reference with four substeps is reused, training on seeds 1000–1047, development on seeds 2000–2011. The new test will remain separate. The solver corrects the displacement of the smoke with a midpoint backtrace and, in the temporal variant, a two-level estimate of the velocity over time. A trained spectral operator corrects the transport and diffusion response without additional transforms.
Exploration of 64/80/96 grids, linear or cubic interpolation, midpoint backtrace and temporal variant, filter strength 0.5, 1 and 1.5. For every variant the classical ablation with the filter switched off is included. The MacCormack and linear/cubic references of the previous attempt are re-evaluated in the same process. On validation we look for a variant that lowers the error relative to the classical front at the same latency. If there is no advantage, development can continue before the new test is fixed.
